Preprocessing QC — the whole experiment in ten seconds

AOT 7T dataset · per-run mean EPI videos · one frame per run

Each video plays through every AOT run of one participant's experiment in chronological order (9–12 sessions, 90–120 runs), at one frame per run and about ten seconds total. A frame is the time-average of that run's fully preprocessed BOLD series (space-T1w, 1.25 mm, NORDIC + slice-timing), shown as axial / coronal / sagittal mid-slices with the session and run stamped top-left. Because every run is resampled into the same anatomical space, a well-preprocessed experiment should look like a still photograph: anatomy pinned in place across months of scanning, with only slow intensity changes.

How to read the two variants

Fixed window — one intensity scale for the whole experiment (0 to the global 99th percentile). Signal drift, coil-sensitivity changes, or a session with different gain show up as flicker in brightness; nothing is autoscaled away.
Normalized — each run windowed to its own 99th percentile. Brightness is equalized, so what remains is pure geometry: registration stability, dropout footprint, vessel patterns. A jump here that is absent in the fixed-window version is a spatial problem, not an intensity one.
